# #1071 GPU probes
Scripts used to measure the NEWT glide frame on the GPU (see PR 1073). gpu.js: coloured-pixel count of a held frame (env XS, DBG, FORCE); probe_gen.js + probe.js/probe2.js: run ix0_roots on the GPU for chosen w; zt.js/zt2.js: GPU cx_zeta vs CX.zeta; cmp8.js: share vs window-clipped truth; *.diff: temporary shader experiments (not applied).
